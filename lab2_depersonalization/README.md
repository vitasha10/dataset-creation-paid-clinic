## Функциональность

### 1. Чтение входного файла
Загрузка XLSX файла из лабораторной работы №1 с оптимизацией для больших файлов.

### 2. Выбор столбцов для обезличивания
**ВАЖНО**: Выбор определяет, какие столбцы обезличивать, НЕ какие использовать для K-anonymity.
K-anonymity всегда считается по ВСЕМ столбцам датасета!

Все столбцы **по умолчанию выбраны** для обезличивания.

### 3. Обезличивание данных (предопределенные методы)

Каждый столбец обезличивается своим методом:

- **ФИО** → Пол (Мужской/Женский) - определение по имени из списков
- **Паспортные данные** → Регион ("Москва", "Санкт-Петербург")
- **СНИЛС** → Возрастная группа ("18-25 лет", "26-35 лет", "36-45 лет", "46-55 лет", "56-65 лет", "66+ лет")
- **Симптомы** → Обобщение по количеству ("Несколько симптомов (2-3)")
- **Выбор врача** → Расширенные категории специалистов (15+ категорий)
  - Общая медицина
  - Кардиология и сосуды
  - Неврология
  - Психическое здоровье
  - Внутренние органы
  - Хирургия
  - Органы чувств
  - Дерматология
  - Репродуктивное здоровье
  - Онкология
  - Инфекционные заболевания
  - Иммунология и аллергология
  - Стоматология
  - Реабилитация
  - Диетология
  - Педиатрия
- **Дата посещения** → Год и квартал ("2025-Q3")
- **Анализы** → Обобщение по количеству ("Один анализ")
- **Дата получения анализов** → Год и квартал ("2025-Q3")
- **Стоимость анализов** → Диапазоны ("1000-2000 руб.")
- **Карта оплаты** → Название банка ("Сбербанк", "ВТБ") ИЛИ платежная система ("МИР", "Visa")

### 4. Расчет K-анонимности
**Вычисляется по ВСЕМ столбцам датасета**, независимо от выбора!

### 5. Топ плохих значений K
Отображение топ-5 наименьших значений K с процентами от всего датасета.

### 6. Уникальные строки
Отображение строк с K=1 (уникальные комбинации по всем столбцам).

### 7. Оценка полезности данных

**ПРАВИЛЬНЫЙ ПОДХОД (исправлено в 7c094fc):**

Оценка полезности теперь использует **две метрики**:

1. **KLD (Kullback-Leibler Divergence)** - только для обобщенных атрибутов:
   - Симптомы, Выбор врача, Даты, Анализы, Стоимость
   - Показывает изменение распределения данных
   - KLD ~20-30 НОРМАЛЬНО для агрессивного обобщения!

2. **Information Loss** - для всех атрибутов:
   - IL = 1 - (unique_after / unique_before)
   - Показывает долю потерянной уникальной информации
   - Более интуитивная метрика для пользователя

**Почему KLD не для всех столбцов?**
- ФИО→Пол, СНИЛС→Возраст - это **ЗАМЕНА**, не обобщение
- KLD имеет смысл только там, где сохраняется смысл атрибута
- Подробности в файле `АНАЛИЗ_ПРОБЛЕМ_KLD_И_K_ANONYMITY.md`

### 8. Сохранение обезличенного датасета
Экспорт результата в XLSX файл с оптимизацией.

### 9. UI функции
- **Кнопки "Скопировать"** - для быстрого копирования путей файлов
- **Увеличенный статус-бар** - шрифт в 2 раза больше для лучшей читаемости

## Структура GUI

- **Верхнее меню**: Сохранить, Рассчитать K-anonymity, Обезличить, Сохранить датасет, Выход
- **Левая панель**: Выбор столбцов для обезличивания (все по умолчанию выбраны)
- **Правая панель**: Топ плохих K-anonymity значений (по всем столбцам!)
- **Нижняя панель**: Выбор файлов ввода/вывода с кнопками "Скопировать"
- **Строка состояния**: Увеличенный шрифт (14pt)

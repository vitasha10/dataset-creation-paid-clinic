# Лабораторная работа №2 - Обезличивание данных

Программа для обезличивания датасета платной поликлиники и расчета K-анонимности.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Функциональность

1. **Чтение входного файла** - загрузка XLSX файла из лабораторной работы №1
2. **Выбор квази-идентификаторов** - пользователь может выбрать столбцы для анализа K-анонимности
3. **Обезличивание данных** - применение различных методов обезличивания:
   - Локальное обобщение
   - Агрегация
   - Возмущение
   - Микро-агрегация
   - Перемешивание
   - Создание псевдонимов
   - Маскеризация
   - Локальное подавление
   - Удаление атрибутов
4. **Расчет K-анонимности** - вычисление K-анонимности для выбранных квази-идентификаторов
5. **Топ плохих значений K** - отображение топ-5 наименьших значений K с процентами
6. **Уникальные строки** - отображение строк с K=1
7. **Оценка полезности данных** - расчет расстояния Кульбака-Лейблера (KLD)
8. **Сохранение обезличенного датасета** - экспорт результата в XLSX файл

## Структура GUI

- **Верхнее меню**: Сохранить, Рассчитать K-anonymity, Обезличить, Сохранить датасет, Выход
- **Левая панель**: Выбор квази-идентификаторов (чекбоксы)
- **Правая панель**: Топ плохих K-anonymity значений
- **Нижняя панель**: Выбор файлов ввода/вывода

## Требования к входному файлу

Файл должен содержать следующие столбцы:
- ФИО
- Паспортные данные
- СНИЛС
- Симптомы
- Выбор врача
- Дата посещения врача
- Анализы
- Дата получения анализов
- Стоимость анализов
- Карта оплаты

# Лабораторная работа №2 - Обезличивание данных (ОБНОВЛЕННАЯ ВЕРСИЯ)

Программа для **реального** обезличивания датасета платной поликлиники и расчета K-анонимности.

## ⚠️ КЛЮЧЕВЫЕ ИЗМЕНЕНИЯ

1. **Реальное обезличивание** - ФИО полностью заменяется на псевдонимы (не оставляем фамилии!)
2. **K-anonymity по ВСЕМ столбцам** - рассчитывается для всего датасета, не только выбранных QI
3. **Предопределенные методы** - для каждого столбца свой метод обезличивания
4. **Карта → Банк** - извлекается название банка из BIN-кода
5. **Паспорт → Регион** - извлекается регион из серии паспорта
6. **Оптимизация** - ускорена работа с большими файлами (500К+ строк)

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Функциональность

### 1. Чтение входного файла
Загрузка XLSX файла из лабораторной работы №1 с оптимизацией для больших файлов.

### 2. Выбор столбцов для обезличивания
**ВАЖНО**: Выбор определяет, какие столбцы обезличивать, НЕ какие использовать для K-anonymity.
K-anonymity всегда считается по ВСЕМ столбцам датасета!

Все столбцы **по умолчанию выбраны** для обезличивания.

### 3. Обезличивание данных (предопределенные методы)

Каждый столбец обезличивается своим методом:

- **ФИО** → Псевдонимы ("Пациент_000001") - полная замена
- **Паспортные данные** → Регион ("Москва", "Санкт-Петербург")
- **СНИЛС** → Маскировка ("XXX-XXX-XXX XX")
- **Симптомы** → Обобщение по количеству ("Несколько симптомов (2-3)")
- **Выбор врача** → Категории специалистов ("Общая медицина")
- **Дата посещения** → Год и квартал ("2025-Q3")
- **Анализы** → Обобщение по количеству ("Один анализ")
- **Дата получения анализов** → Год и месяц ("2025-09")
- **Стоимость анализов** → Диапазоны ("1000-2000 руб.")
- **Карта оплаты** → Название банка ("Сбербанк", "ВТБ")

### 4. Расчет K-анонимности
**Вычисляется по ВСЕМ столбцам датасета**, независимо от выбора!

### 5. Топ плохих значений K
Отображение топ-5 наименьших значений K с процентами от всего датасета.

### 6. Уникальные строки
Отображение строк с K=1 (уникальные комбинации по всем столбцам).

### 7. Оценка полезности данных
Расчет расстояния Кульбака-Лейблера (KLD) для оценки потери информации.

### 8. Сохранение обезличенного датасета
Экспорт результата в XLSX файл с оптимизацией.

## Структура GUI

- **Верхнее меню**: Сохранить, Рассчитать K-anonymity, Обезличить, Сохранить датасет, Выход
- **Левая панель**: Выбор столбцов для обезличивания (все по умолчанию выбраны)
- **Правая панель**: Топ плохих K-anonymity значений (по всем столбцам!)
- **Нижняя панель**: Выбор файлов ввода/вывода

## Требования к входному файлу

Файл должен содержать следующие столбцы:
- ФИО
- Паспортные данные
- СНИЛС
- Симптомы
- Выбор врача
- Дата посещения врача
- Анализы
- Дата получения анализов
- Стоимость анализов
- Карта оплаты

## Примеры преобразований

### До обезличивания:
```
ФИО: Михайлов Борис Максимович
Паспорт: 1625 497540
СНИЛС: 885-502-258 31
Карта: 2200 0897 4704 5877
Дата посещения: 2025-09-10T16:00+03:00
Стоимость: 680 руб.
Врач: терапевт
```

### После обезличивания:
```
ФИО: Пациент_000001
Паспорт: Республика Татарстан
СНИЛС: XXX-XXX-XXX XX
Карта: Газпромбанк
Дата посещения: 2025-Q3
Стоимость: До 1000 руб.
Врач: Общая медицина
```

## Реализованные модули

### 1. depersonalization_methods.py
**Назначение**: Методы обезличивания данных

**Класс**: `DepersonalizationMethods`

**Методы**:
- `generalization_local()` - Локальное обобщение
- `aggregation()` - Агрегация данных
- `perturbation()` - Возмущение (добавление шума)
- `microaggregation()` - Микро-агрегация
- `shuffling()` - Перемешивание значений
- `pseudonymization()` - Создание псевдонимов
- `masking()` - Маскеризация данных
- `suppression_local()` - Локальное подавление
- `attribute_removal()` - Удаление атрибутов

**Примеры работы**:
```
ФИО: "Иванов Иван Иванович" → "Иванов И. И."
Паспорт: "1234 567890" → "XXXX XXXXXX"

Карта: "1234 5678 9012 3456" → "1234 XXXX XXXX 3456"
Дата: "2025-09-10T16:00+03:00" → "2025-09"
Стоимость: "680 руб." → "0-1000 руб."
```

### 2. k_anonymity.py
**Назначение**: Расчет K-анонимности

**Класс**: `KAnonymityCalculator`

**Методы**:
- `calculate_k_anonymity()` - Основной расчет K
- `get_top_bad_k_values()` - Топ-N плохих значений K
- `get_unique_rows()` - Строки с K=1
- `get_acceptable_k()` - Требуемое K для размера
- `check_k_threshold()` - Проверка соответствия

**Результаты**:
```

Среднее K: 1.27

K=1: 605 записей (60.5000%)
K=2: 300 записей (30.0000%)
K=3: 75 записей (7.5000%)
K=4: 20 записей (2.0000%)
```

### 3. utility_evaluator.py
**Назначение**: Оценка полезности обезличенных данных

**Класс**: `DataUtilityEvaluator`

**Методы**:
- `calculate_kld()` - Расчет KLD для столбцов
- `evaluate_utility()` - Комплексная оценка
- `calculate_overall_kld()` - Общий KLD

**Формула KLD**:
```
KLD(P||Q) = Σ P(i) * log₂(P(i)/Q(i))
```

**Интерпретация**:
- KLD < 0.1 : Отличная полезность
- KLD < 0.5 : Хорошая полезность
- KLD < 1.0 : Удовлетворительная полезность
- KLD < 2.0 : Низкая полезность
- KLD >= 2.0: Очень низкая полезность

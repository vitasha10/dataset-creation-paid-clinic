### Интерфейс программы

Программа имеет следующие основные элементы:

#### 1. Верхнее меню
- **Файл**
  - Открыть датасет
  - Сохранить датасет
  - Выход
- **Операции**
  - Рассчитать K-anonymity
  - Обезличить
  - Оценить полезность данных

#### 2. Левая панель - Выбор квази-идентификаторов
Отображает список всех столбцов датасета с чекбоксами:
- ☑ ФИО
- ☑ Паспортные данные
- ☑ СНИЛС
- ☐ Симптомы
- ☐ Выбор врача
- ☐ Дата посещения врача
- ☐ Анализы
- ☐ Дата получения анализов
- ☐ Стоимость анализов
- ☐ Карта оплаты

Кнопки:
- **Выбрать все** - выбрать все квази-идентификаторы
- **Очистить** - снять все галочки

#### 3. Правая панель - Топ плохих K-anonymity
Отображает результаты анализа K-анонимности:
- Общую статистику
- Топ-5 наименьших значений K с процентами
- Количество уникальных строк (K=1)
- Проверку соответствия требуемому K

#### 4. Нижняя панель - Файлы
- **Имя файла ввода** - путь к исходному датасету
- **Имя файла вывода** - путь для сохранения обезличенного датасета
- Кнопки **Выбрать...** для выбора файлов

#### 5. Строка состояния
Отображает текущий статус программы и информацию о загруженном датасете.

## Методы обезличивания

Программа поддерживает 9 методов обезличивания:

### 1. Локальное обобщение
Заменяет точные значения на более общие категории:
- **ФИО**: "Иванов Иван Иванович" → "Иванов И. И."
- **Паспорт**: "1234 567890" → "1234 XXXXXX"
- **Дата**: "2025-09-10T16:00+03:00" → "2025-09"
- **Стоимость**: "680 руб." → "0-1000 руб."
- **Карта**: "1234 5678 9012 3456" → "123456 XXXX XXXX XXXX"

### 2. Агрегация
Объединяет записи в группы и заменяет значения на групповые:
- Стоимость округляется до ближайших 500 рублей

### 3. Возмущение
Добавляет случайный шум к числовым данным:
- **Стоимость**: добавляется случайное отклонение (±10%)
- **Дата**: добавляется случайное смещение (±3 дня)

### 4. Микро-агрегация
Группирует записи по k элементов и заменяет значения на среднее по группе:
- Применяется к числовым полям (стоимость)

### 5. Перемешивание
Случайная перестановка значений внутри столбца:
- Разрывает связь между строками

### 6. Создание псевдонимов
Замена идентификаторов на псевдослучайные значения:
- **ФИО**: → "Клиент_00001"
- **СНИЛС**: → "XXX-XXX-XXX 01"
- **Паспорт**: → "XXXX XXXXXX"
- **Карта**: → "XXXX XXXX XXXX XXXX"

### 7. Маскеризация
Частичное скрытие данных:
- **ФИО**: "Иванов Иван Иванович" → "Иванов И*** И***"
- **СНИЛС**: "123-456-789 01" → "XXX-XXX-XXX XX"
- **Паспорт**: "1234 567890" → "XXXX XXXXXX"
- **Карта**: "1234 5678 9012 3456" → "1234 XXXX XXXX 3456"

### 8. Локальное подавление
Удаление редких значений (встречающихся реже порогового значения):
- Заменяет редкие значения на '*'

### 9. Удаление атрибутов
Полное удаление выбранных столбцов из датасета

## K-анонимность

### Что такое K-анонимность?

K-анонимность - это мера приватности данных. Датасет обладает k-анонимностью, если каждая комбинация квази-идентификаторов встречается как минимум k раз.

### Квази-идентификаторы

Квази-идентификаторы (QI) - это атрибуты, которые сами по себе не идентифицируют человека, но в комбинации могут это сделать:
- ФИО
- Паспортные данные
- СНИЛС
- Дата посещения
- и т.д.

### Расчет K-anonymity

Программа рассчитывает:
1. **Минимальное K** - наименьшее количество записей с одинаковой комбинацией QI
2. **Максимальное K** - наибольшее количество
3. **Среднее K** - среднее значение
4. **Количество уникальных комбинаций** - различных комбинаций QI

### Топ плохих K-anonymity

Программа выводит топ-5 наименьших значений K с указанием:
- Значения K
- Количества записей
- Процента от общего количества

Пример:
```
K=1: 605 записей (60.5000%)
K=2: 300 записей (30.0000%)
K=3: 75 записей (7.5000%)
```

### Уникальные строки (K=1)

Строки с K=1 являются уникальными и потенциально идентифицируемыми. Программа отображает их количество.

### Требуемое K

В зависимости от размера датасета, программа определяет требуемое значение K:
- до 51,000 записей: K ≥ 10
- до 105,000 записей: K ≥ 7
- до 260,000 записей: K ≥ 5

## Оценка полезности

### Расстояние Кульбака-Лейблера (KLD)

KLD измеряет различие между распределениями данных в исходном и обезличенном датасете.

**Формула:**
```
KLD(P||Q) = Σ P(i) * log₂(P(i)/Q(i))
```

где:
- P - распределение исходных данных
- Q - распределение обезличенных данных

### Интерпретация KLD

- **KLD < 0.1**: Отличная полезность (минимальные изменения)
- **KLD < 0.5**: Хорошая полезность (небольшие изменения)
- **KLD < 1.0**: Удовлетворительная полезность (умеренные изменения)
- **KLD < 2.0**: Низкая полезность (значительные изменения)
- **KLD ≥ 2.0**: Очень низкая полезность (существенные изменения)

### Компромисс между приватностью и полезностью

Более агрессивное обезличивание (большее K) приводит к:
- ✓ Лучшей приватности
- ✗ Меньшей полезности данных (больший KLD)

Необходимо найти баланс между защитой данных и сохранением их аналитической ценности.

## Примеры использования

### Пример 1: Базовое обезличивание

1. Запустите программу: `python main.py`
2. Выберите **Файл → Открыть датасет**
3. Выберите файл из Lab 1 (например, `clinic_dataset_1k.xlsx`)
4. В левой панели выберите квази-идентификаторы (ФИО, Паспортные данные, СНИЛС)
5. Выберите **Операции → Рассчитать K-anonymity**
6. Просмотрите результаты в правой панели
7. Выберите **Операции → Обезличить**
8. Выберите методы обезличивания (например, Маскеризация, Локальное обобщение)
9. Нажмите **Применить**
10. Просмотрите обновленные результаты K-anonymity
11. Выберите **Операции → Оценить полезность данных**
12. Просмотрите KLD для каждого столбца
13. Выберите **Файл → Сохранить датасет** для сохранения результата

### Пример 2: Использование без GUI (скрипт)

```python
import pandas as pd
from depersonalization_methods import DepersonalizationMethods
from k_anonymity import KAnonymityCalculator
from utility_evaluator import DataUtilityEvaluator

# Загрузка данных
df = pd.read_excel('input.xlsx')

# Обезличивание
depers = DepersonalizationMethods()
df_anon = depers.masking(df.copy(), 'ФИО')
df_anon = depers.generalization_local(df_anon, 'Дата посещения врача')

# K-anonymity
k_calc = KAnonymityCalculator()
qi = ['ФИО', 'Паспортные данные', 'СНИЛС']
k_analysis = k_calc.calculate_k_anonymity(df_anon, qi)
print(f"Min K: {k_analysis['min_k']}")

# Полезность
evaluator = DataUtilityEvaluator()
utility = evaluator.evaluate_utility(df, df_anon, qi)
print(f"KLD: {utility['overall_kld']}")

# Сохранение
df_anon.to_excel('output.xlsx', index=False)
```

### Пример 3: Итеративное обезличивание

Для достижения требуемого K-anonymity может потребоваться несколько итераций:

1. Рассчитайте K-anonymity
2. Если K < требуемого, примените обезличивание
3. Пересчитайте K-anonymity
4. При необходимости примените дополнительные методы
5. Повторяйте до достижения нужного K
6. Оцените полезность данных
